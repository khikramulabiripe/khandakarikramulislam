# Khandakar Ikramul Islam — Deep Ocean Portfolio

Static, responsive portfolio with a five-frame scroll story, large left-side Best Work media galleries, animated “See More” characters and category project libraries.

For the complete Bangla-friendly editing and publishing guide, read [`readme.txt`](readme.txt).

## Quick start

1. Put landing frames in `assets/landing/` as `pic1.jpg` through `pic5.jpg`.
2. Open `index.html`, or run `python -m http.server 8000` in this folder.
3. Add projects with `codegenerator.html` locally, then paste its output into `projects.js`.
4. For the large left-side Best Work gallery, store files in `assets/work/` and use the generated `workMedia` field.

`codegenerator.html` is intentionally not linked from the site. It is a private helper and should not be deployed.
